# MOR Power logo

The Smart Outlet Shield mark represents protection, power, and connected telemetry.

## Assets

- `smart-outlet-shield.svg` — transparent master, cyan-to-blue shield.
- `smart-outlet-shield-mono.svg` — single-color navy treatment.
- `smart-outlet-shield-reversed.svg` — cyan/blue mark on navy.
- `smart-outlet-app-icon.svg` — square app icon.
- `png/` — transparent square 512 and 1024 mark exports, portrait exports, mono/reversed raster variants, and the 1024 × 1024 app icon.
- `/public/favicon.svg`, `favicon.png`, and `favicon-16.png` — browser favicons.

Keep clear space around the mark equal to one circuit node. Do not stretch, rotate, or recolor the master. Use the monochrome mark on busy backgrounds and the reversed mark on dark navy surfaces. Minimum digital height is 24 px.

The in-app animated vector lives in `src/components/PowerShieldMark.tsx`; the SVG master is the canonical handoff asset.
